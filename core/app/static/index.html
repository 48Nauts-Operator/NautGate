Scheduled probes fire a fixed suite at each max-subscription model on both the subscription path (OAuth) and a metered twin (OpenRouter/API), then compare. Detects silent model swaps, tokenizer shifts, latency/quality drift, and cross-path divergence. Statistical evidence, not cryptographic proof.

Config, targets & open alerts
Config

Subscription legs need NAUTGATE_ANTHROPIC_OAUTH_TOKEN / NAUTGATE_CHATGPT_OAUTH_TOKEN in deploy/.env. These OAuth tokens expire — an auth_expired alert means re-paste it.

What prompt caching is actually doing for you. The first call writes a repeated prefix (25% premium), later calls read it at ~1/10th input price. Hit rate = input tokens served from cache. Saved = read discount minus write premium. The leak detector flags prefixes that write but rarely read back — usually a timestamp/ID sneaking into an otherwise-stable prompt.

Select a call to inspect its token anatomy, prompt & response.

What your connected tools actually cost and save. Every request carries the schemas of every connected MCP (the carrying cost); every answer a graph or MCP call gives in one shot replaces a chain of Read/Grep crawling (the saving). Both are measured from captured traffic.

Learn from your own prompts. The judge flags what a prompt was missing, writes the rewrite it would have sent, and ▶ simulate actually runs that rewrite against the same model — blind-judged, with the price difference. The habits panel shows your recurring patterns so the lesson sticks.

Print-ready reports built from the audit log — what every agent sent through the LLMs, what it cost, what data categories shipped where, and what the judge thought of the answers. Bodies are never included; safe to hand to a client or auditor.

The brain layer. Each (provider, model, tier) accumulates a score in [0, 1] starting at 0.50. Bloat findings subtract; clean requests slowly add. Score < 0.30 → routing demotes the model and falls through to the tier's fallback. Penalties decay with a 7-day half-life.

Master → Sub-agent Delegation Graph

Offline mode

        
Air-gapped / on-prem demos. NautGate stops making any outbound call on a timer — the provider heartbeat, LLM probes and the OpenRouter credits lookup all stand down. Serving traffic is unaffected: local models and every routed request keep working. Takes effect within a minute, no restart. Set NAUTGATE_OFFLINE=1 to force it on and lock this toggle out.

Engram-OSS memory ingest

        
When enabled, every completed request also writes a user-prompt + assistant-reply pair into a remote memories table — same shape FlowAI's flow-proxy used. This feeds your Engram-OSS memory store (pgvector / Neo4j / Qdrant). Toggle off if you don't run it. Password is read from the gateway's MEMORY_DB_PASSWORD env var, not the UI.


        

          
          
          
          
          
          
          
          
        

      


      
      

        
Quality eval (Prompt Coach)

        
Each completed request can be reviewed by a cheap judge model. Anomalies (empty responses, errors, disconnects, high bloat) are always evaluated; everything else is sampled at the rate below. Daily cap caps the judge spend per UTC day. The judge call goes direct to the configured provider — never through NautRouter, so it doesn't pollute routing analytics. API key is read from the provider's env var (OPENROUTER_API_KEY for openrouter, OPENAI_API_KEY for openai, none for lmstudio).

Backups 

        
Full snapshots of the nautgate schema (audit log, scorecard, drift baselines, keys, projects — everything). Stored on the gateway host under ~/.nautgate/backups/ as gzipped SQL. Scheduled backups run in the background; restore is destructive (drops the schema before reloading) and requires explicit confirmation.
