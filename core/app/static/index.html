Audit log

Every LLM call as it happens. The token bar shows where the tokens *go* — system / tools / history / current user — so you can spot CLI bloat (a "hi" prompt shouldn't ship 30 KB of system + 12 tool defs). Click any row for full metadata.

Model Scorecard

The brain layer. Each (provider, model, tier) accumulates a score in [0, 1] starting at 0.50. Bloat findings (excessive context, history dominance, unused tools, oversized payload) subtract; clean requests slowly add. Score < 0.30 → routing demotes the model and falls through to the tier's fallback. Penalties decay with a 7-day half-life. Click an incident to see the audit detail.

Behavior Drift

Catches silent provider-side changes. Per (provider, model, metric) we maintain an EWMA baseline and z-score every new sample. 3+ consecutive |z| > 3 anomalies raise an alert. Tracked: input_tokens_per_byte (tokenizer/cache change), response_size_bytes (verbosity drift), first_byte_ms, duration_ms, and messages_count_delta (compaction events). Compaction fires immediately on a sharp drop, not after warmup.

Engram-OSS memory ingest

        
When enabled, every completed request also writes a user-prompt + assistant-reply pair into a remote memories table — same shape FlowAI's flow-proxy used. This feeds your Engram-OSS memory store (pgvector / Neo4j / Qdrant). Toggle off if you don't run it. Password is read from the gateway's MEMORY_DB_PASSWORD env var, not the UI.


        

          
          
          
          
          
          
          
          
        

      


      
      

        
Quality eval (Prompt Coach)

        
Each completed request can be reviewed by a cheap judge model. Anomalies (empty responses, errors, disconnects, high bloat) are always evaluated; everything else is sampled at the rate below. Daily cap caps the judge spend per UTC day. The judge call goes direct to the configured provider — never through NautRouter, so it doesn't pollute routing analytics. API key is read from the provider's env var (OPENROUTER_API_KEY for openrouter, OPENAI_API_KEY for openai, none for lmstudio).


        

          
          
          
          
          
          
          
          
        

      


      
      

        
Backups 

        
Full snapshots of the nautgate schema (audit log, scorecard, drift baselines, keys, projects — everything). Stored on the gateway host under ~/.nautgate/backups/ as gzipped SQL. Scheduled backups run in the background; restore is destructive (drops the schema before reloading) and requires explicit confirmation.
